# SEO план: структура страниц + семантика

## 0) Цель и позиционирование
- Цель: стабильный органический трафик + заявки на консультацию и курсы.
- Позиционирование: мини‑группы до 3 человек, практика и реальный опыт, выход на первые деньги во время обучения.
- Бренд: IT‑школа Peaky Minds.

## 1) Структура новых страниц (SEO‑каркас)

### 1.1 Разделы сайта
- Главная: / (лендинг школы)
- Курсы:
  - /courses/fullstack
  - /courses/data-science
  - /courses/business
- Блог: /blog
- Гайды/База знаний: /guides
- О школе: /about
- Отзывы/кейсы: /reviews
- FAQ: /faq
- Контакты: /contacts

### 1.2 Новые SEO‑страницы под спрос (коммерческие посадочные)
- /courses/python-from-zero — «Курс Python с нуля»
- /courses/backend-fastapi — «Курс Backend разработчика FastAPI»
- /courses/data-science-practice — «Курс Data Science с практикой»
- /courses/python-for-business — «Python для бизнеса / автоматизация»
- /courses/mini-groups — «Обучение программированию в мини‑группах»

### 1.3 Шаблон блока для новых SEO‑страниц (структура)
1) Hero: H1 + подзаголовок + CTA + 3 мини‑преимущества
2) Кому подходит (3 карточки)
3) Результат (6–10 буллетов)
4) Стек и формат (бейджи + мини‑блок)
5) Программа по модулям (4–8)
6) Реализация в работу (таймлайн)
7) Кейсы/проекты (3–6 карточек)
8) Отзывы (2–4 коротких кейса)
9) FAQ (6–10)
10) Финальный CTA

### 1.4 Визуальная подача SEO‑разделов (чтобы выглядело хорошо)
- Держать единый стиль из `docs/DESIGN_SYSTEM.md`: Prata + Sora, glass‑карточки, мягкий glow, атмосферный фон.
- Контентные страницы (блог/гайды): чтение в 2 колонки (контент 680–760px + сайдбар 240–280px), на mobile — 1 колонка.
- Hero для SEO‑страниц: большой H1, лид‑абзац, 3 мини‑преимущества и CTA; справа — визуал (код/карточки/мини‑метрики).
- Карточки статей: category‑pill, время чтения, 1 ключевая польза; hover‑lift + тонкий glow.
- Визуалы: обложки 16:9, одинаковый стиль (градиент + код/абстракция), единый шрифт для подписей.
- Статья: sticky TOC, callout‑блоки (Важно/Ошибка/Пример), код‑блоки в моно, CTA на 30–40% и в конце.
- Цветовые акценты по направлениям: Full‑stack → `--accent-2`, Data Science → `--accent-1`, Business → `--accent-3`.

## 7) План реализации (поэтапно)
1) Утвердить список SEO‑страниц и URL.
2) Подготовить структуру блоков для каждой страницы.
3) Сформировать первичную семантику (таблица ключей → страниц).
4) Добавить базовые SEO‑метаданные (Title/Description/H1) по страницам.
5) Запустить блог и первые 8–10 статей.
6) Настроить перелинковку и CTA в статьях.
7) Через 4–6 недель расширить статьи и кластеры.
8) Сделать UI‑шаблон для контентных страниц (листинг, статья, гайд) с TOC, callout и CTA.
9) Подготовить набор визуальных шаблонов (обложки статей, схемы, иллюстрации) в едином стиле.
