# Переменные окружения

## Админ-доступ

Админ-панель проверяет Telegram ID через переменную окружения:

```env
ADMINS_IDS=11,22,33
```

ID можно разделять запятыми, пробелами или переносами строк. Значение нужно добавить в `config/.env` на сервере и перезапустить приложение.

`data/telegram_whitelist.json` остается списком получателей Telegram-уведомлений и пользователей команд бота. Он больше не является основным источником прав доступа к админке, если `ADMINS_IDS` задан.
