# SEO‑страницы: детальная структура и визуальная подача

## 1) Общие правила (чтобы выглядело дорого и цельно)
- Сетка: контейнер 1200–1240px, базовый шаг 8px.
- Чтение: ширина текста 680–760px, межстрочный 1.6–1.7.
- Типографика: H1/H2 - Prata; текст - Sora; код - JetBrains Mono.
- Карточки: glass‑фон + тонкий stroke + мягкий glow + hover‑lift.
- Фон: radial‑подсветка + линейный градиент, без плоских заливок.
- Акцентные цвета по направлению:
  - Full‑stack → `--accent-2` (mint)
  - Data Science → `--accent-1` (amber)
  - Business → `--accent-3` (coral)

---

## 2) Шаблон SEO‑посадочной (курс/направление)

### Блок 1 - Hero
- H1 + подзаголовок + 3 мини‑преимущества + 1 primary CTA.
- Справа: визуал (карточка проекта + код‑фрагмент + мини‑метрики).
- Под H1: 2–3 короткие строковые выгоды (формат pill).

### Блок 2 - «Кому подходит»
- 3 карточки персонажей (кто, боль, желаемый результат).

### Блок 3 - «Что получите»
- 6–10 результатов, 2 колонки на desktop.

### Блок 4 - «Стек и формат»
- Лента бейджей + мини‑описание формата (группа, частота, длительность).

### Блок 5 - «Программа по модулям»
- 4–8 модулей: название + 3 пункта + мини‑проект.

### Блок 6 - «Реализация в работу»
- Таймлайн 4–5 шагов (портфолио → реальные задачи → тестовые → собеседования).

### Блок 7 - «Проекты и портфолио»
- Сетка 3–6 карточек: задача → стек → результат.

### Блок 8 - «Отзывы/кейсы»
- 2–4 карточки в формате «было → стало».

### Блок 9 - «FAQ»
- 6–10 вопросов, аккордеон.

### Блок 10 - Финальный CTA
- Большая карточка с формой/кнопкой, фон‑градиент.

---

## 3) Блог: листинг ( /blog )
- Hero: H1 + подзаголовок + строка поиска + 6–10 фильтров‑тегов.
- Блок «Избранная статья»: 1 большая карточка слева, 2 малых справа.
- Основной список: сетка 3×N, карточки с category‑pill, временем чтения и ключевой пользой.
- Нижний CTA: «Получить план обучения» + ссылка на консультацию.

---

## 4) Гайды/База знаний: листинг ( /guides )
- Hero: H1 + объяснение пользы + CTA.
- Блок «Маршруты обучения»: 3 карточки путей (Backend / DS / Business).
- Список гайдов: вертикальные карточки с кратким списком шагов.

---

## 5) Статья ( /blog/* и /guides/* )

### Верх статьи
- H1, лид‑абзац, метаданные (автор, дата, время чтения).
- Справа: sticky TOC + CTA‑кнопка (мини).

### Тело статьи
- Ритм: 3–4 абзаца → список → callout → пример → вывод.
- Callout‑блоки: «Важно», «Ошибка», «Пример», «Шаблон».
- Код‑блоки: контрастный фон, JetBrains Mono, горизонтальный скролл.

### CTA и навигация
- CTA после 30–40% статьи (мини‑форма или кнопка).
- В конце: блок «Следующий шаг» + 3 релевантных статьи + курс.

## 6) Специфика новых SEO‑посадочных

### /courses/python-from-zero
- Упор: «с нуля», «первые проекты», «план на 3–6 месяцев».
- Визуал: таймлайн «1‑й месяц → 3‑й → 6‑й».

### /courses/backend-fastapi
- Упор: API‑сервисы, архитектура, тестирование, деплой.
- Визуал: карточка «пример API» + схема эндпоинтов.

### /courses/data-science-practice
- Упор: портфолио + реальные задачи + стажировка.
- Визуал: пайплайн «данные → модель → API».

### /courses/python-for-business
- Упор: «быстрые решения для бизнеса», ROI, кейсы автоматизации.
- Визуал: «до/после» в цифрах.

### /courses/mini-groups
- Упор: формат обучения, плотность обратной связи, результат.
- Визуал: сравнение «мини‑группа vs поток».
